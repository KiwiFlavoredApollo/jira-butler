# README

핏자 버틀러는 Jira 프로젝트의 진척도를 알려주는 디스코드 봇입니다.

## 기술스택

- Python
- discord.py

## 명령어

### `/setup <project>`

Jira 프로젝트를 설정합니다.

### `/sprint progress <sprint>`

스프린트의 진척도를 확인합니다. 디스코드 입력창에서 사용 가능한 스프린트 목록을 보여줍니다. 스프린트의 진척도는 스토리를 기준으로 합니다.

### `/project progress`

프로젝트의 진척도를 확인합니다. 프로젝트의 진척도는 스토리를 기준으로 합니다.

## 진척도 가중치

Jira에는 우선 순위가 다섯 단계로 되어있습니다. 진척도를 계산할 때 가중치는 1, 2, 3, 5, 8의 피보나치 스케일링을 사용합니다.
